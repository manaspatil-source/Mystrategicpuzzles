Position of the survivor


There are 53 people standing in a line, numbered from 1 to 53. You may choose any starting position.

A dictator repeatedly conducts elimination rounds using this fixed repeating pattern:

4, 2, 3, 3, 2, 3, 4, 2, 3, 4, 2, 3, ...

In each round, the next number in the pattern is used.

If the number is N:

Starting from the front of the current line, only every N-th person survives. Everyone else is eliminated.

After each round, the survivors form a new line, keeping their original relative order.

If N is larger than the number of people remaining, that round is skipped and the next number in the pattern is used.

The process continues until only one person remains.



Question:

Which starting position should you choose to guarantee survival?
